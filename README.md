# PUNIQ Demo — Aziza

Interactive demo of the PUNIQ × Aziza pilot: a national store network map
with live simulated telemetry, built for an investor/partner pitch.

Aziza's Tunisia network spans 206 stores nationwide, and this demo plots
all of them with real geolocation data.

## Stack

- Vite + React (JavaScript)
- React Router
- Recharts
- react-simple-maps + topojson-client + d3-geo (Tunisia map, offline)

## Run

```
npm install
npm run dev
```

Opens on `http://localhost:5173`.

## Data

`src/data/aziza_stores.json` — 206 real geolocated Aziza stores (code,
storename, ville, delegation, address, lat/lon). This is the only real
data in the project — every other figure (savings, energy costs, footfall,
health scores, sensor readings, etc.) is simulated for demo purposes.

`src/data/azizaStores.js` loads that JSON and adds `directeur` / `tel`
fields, since the raw dataset doesn't ship contact info — both are
generated deterministically from each store's `code` (same PRNG-seeding
convention as the rest of the app), so they're placeholders, not real
contacts.

## Structure

- **Page 1 — national map** (`src/pages/MapScreen.jsx`): Tunisia map with all
  206 stores, an overview panel (live counters, event feed, connect
  simulation controls), single-page/no routing between screens.
- **Store overlay** (`src/components/StoreOverlay.jsx`): opens on marker
  click, four tabs —
  - **Overview** — per-store hero metrics, health gauge, "add to
    simulation" for unconnected stores.
  - **Dashboard** — live retail zone monitoring (Réfrigération,
    Climatisation, Éclairage, Caisses, Solaire) with a fault simulator.
  - **Discovery** — radar-style sensor scan and plug-and-play device
    integration flow.
  - **Intelligence** — 14-day energy cost trend, insight cards
    (fault-driven + standing recommendations), ROI statement, roadmap
    teaser.

State lives in two React contexts: `NetworkContext` (store list, connection
state, simulation mode) and `FaultContext` (active simulated faults per
store).

## Simulated metrics

All numbers beyond store name/location/address are generated by
`src/utils/metricsEngine.js`, a PRNG seeded from each store's code (not
`Math.random()` directly). This means every figure is deterministic and
consistent — the same store always shows the same numbers, no matter how
many times you open it — while different stores show different, plausible
values. None of it is real Aziza performance data.
